A single original one-line alibi, printed by a tiny Python program. One line, at most 200 characters, in which a robot vacuum explains why it missed a spot — the whole entry for make.fun's The Vacuum's Alibi.

## The line

> The spot was under the cat. I attempted negotiation. The cat declined. I logged it as occupied territory and moved on.

## Run it

```sh
python3 main.py
```

It prints the line to stdout and, when `MAKEFUN_OUTPUT_DIR` is set, also writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
